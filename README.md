# Paytm Clone

## Project Description
This project is a static Paytm-style clone focused on recharge and bill payment user interfaces across multiple service types.

## Objective
- Build service-based payment UI pages.
- Practice consistent forms and information layout across many modules.
- Recreate a utility-payment style navigation flow.

## Tech Stack
- HTML5
- CSS3

## Project Structure
- `index.html`: Main landing page.
- `recharge.html`: Mobile recharge page.
- `electricity.html`: Electricity bill payment page.
- `cylinder.html`: Gas cylinder booking/payment page.
- `broadband.html`: Broadband payment page.
- `dth.html`: DTH recharge page.
- `education.html`: Education fee payment page.
- `metro.html`: Metro recharge page.
- `style.css`: Core/common styles.
- `rechargeBillPayment.css`: Recharge and bill-payment component styles.
- `navFooter.css`: Shared nav/footer styling.

## Key UI Features
- Multi-service payment page structure.
- Consistent section design for bill/recharge flows.
- Shared header and footer presentation.

## How To Run
1. Open the `Paytm-clone` folder in VS Code.
2. Open `index.html` in your browser.
3. Explore each service page from the listed HTML files.
4. Optional: Use Live Server for auto-refresh.

## Customization Guide
- Update service forms and labels in each HTML file.
- Modify common design tokens in `style.css`.
- Refine payment form visuals in `rechargeBillPayment.css`.
- Keep shared layout styles in `navFooter.css`.

## Current Scope
- Frontend-only implementation.
- No real payment gateway integration.
